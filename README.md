# La Pesca del Futbolista — V4

Versión actualizada a la temporada 2026/27 (datos comprobados con fuentes actuales consultadas el 7 de octubre de 2026).

## Incluye
- 100+ jugadores (actualmente más de 150 registros).
- Jugadores de múltiples ligas y equipos.
- Selección aleatoria: 5 jugadores por partida, sin repetir.
- Progresión: fácil → media → difícil → experto → experto.
- Pistas: posición, nacionalidad y equipo.
- Normalización de nombres para aceptar mayúsculas, minúsculas, tildes y alias habituales.
- 3 vidas y código final `15: 2ULE`.

## Publicar en GitHub Pages
1. Crea un repositorio nuevo en GitHub.
2. Sube `index.html`, `style.css`, `script.js` y `players.js`.
3. En Settings → Pages selecciona la rama principal y `/ (root)`.
4. Guarda y abre la URL que te proporcione GitHub Pages.

## Nota de actualización
Los clubes cambian durante las ventanas de fichajes. Esta versión toma como corte la temporada 2026/27 y la información disponible el 7/10/2026; si hubiera nuevos movimientos posteriores, habría que actualizar `players.js`.
